# Fonts served with the page

## osifont (`osifont-lgpl3fe.ttf`)

The stand-in for **ISOCPEUR** in the typeface list. ISOCPEUR is Autodesk's ISO 3098 lettering, installed with
AutoCAD; it cannot be served from a website, so the page uses it where the computer has it and otherwise this
font, an ISO 3098 lettering made from scratch for free CAD programs.
